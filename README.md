# 🐊 Krokodille · Norsk

Lagspill for å lære norsk: forklar eller tegn ordet på bildet, så laget ditt gjetter – på tid.

**Spill:** https://zagagulena.github.io/krokodille/

- To moduser: *Forklar bildet* og *Tegn ordet*
- To lag, like vanskelige bilder for begge lag, poeng for fart
- Fjernkontroll: styr spillet fra telefonen, eller tegn på telefonen mens den store skjermen viser tegningen
- Fem stiler, egen musikk og lyder, fungerer på svake telefoner
